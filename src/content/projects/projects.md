### CultureBook
**Category**: Android
**Tags**: [Compose, Kotlin, Ktor, Cloud]
**GithubUrl**: https://github.com/Culture-Book

A cultural preservation app developed during my final university year. Built with Jetpack Compose for the Android client and Ktor for the backend, following a cloud-first architecture to ensure scalability and resilience.

### QuestWeaver
**Category**: Android
**Tags**: [Compose, Kotlin, Nearby Connections API]
**GithubUrl**: https://github.com/illutic/QuestWeaver

A Dungeons & Dragons companion app built with Jetpack Compose, leveraging Google's Nearby Connections API for real-time peer-to-peer communication between players at the table.

### Scribblefit
**Category**: Crossplatform
**Tags**: [Compose, Kotlin, SwiftUI, Swift, AI]
**GithubUrl**: https://github.com/illutic/scribblefit

An AI-powered fitness companion app built with a shared KMP core for Android (Compose) and iOS (SwiftUI). Demonstrates full cross-platform code sharing while delivering truly native UI on each platform.
