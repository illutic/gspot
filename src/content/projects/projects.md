### ScribbleFit
**Category**: Crossplatform
**Tags**: [Compose, Kotlin, SwiftUI, Swift, AI, Firebase]
**GithubUrl**: https://github.com/illutic/scribblefit
**DemoUrl**: https://illutic.github.io/scribblefit/

A cross-platform AI fitness tracker that lets users log workouts in natural language — no forms, no dropdowns. An LLM (Gemini) parses freeform text into structured exercises, sets, and reps. Built natively for Android (Jetpack Compose) and iOS (SwiftUI) with MVI architecture, offline-first persistence, and Firebase backend.

### QuestWeaver
**Category**: Crossplatform
**Tags**: [Compose, Kotlin, KMP, SwiftUI, Swift, CI/CD]
**GithubUrl**: https://github.com/illutic/quest_weaver

A Kotlin Multiplatform rewrite of the original QuestWeaver D&D companion app, with native Android (Jetpack Compose) and iOS (SwiftUI) targets sharing a common domain and data layer. Features onboarding flows, real-time session management via Google's Nearby Connections API, and automated CI/CD release pipelines with GitHub Actions.

### GSpot
**Category**: Web
**Tags**: [TypeScript, React, Vite, AWS, CSS]
**GithubUrl**: https://github.com/illutic/gspot
**DemoUrl**: https://illutic.github.io/gspot/

This portfolio site — a modern, high-performance personal portfolio and technical blog built with React 19, TypeScript, and a Vanilla CSS design token system. Follows a Gradle-inspired modular architecture with strict path aliases, zero-dependency i18n (EN/EL), dark/light theming, and serverless edge APIs on Github Pages and AWS Lambda.

### SportsApp
**Category**: Android
**Tags**: [Kotlin, Compose, Clean Architecture, MVI, Modular]
**GithubUrl**: https://github.com/illutic/SportsApp

A modern Android application for browsing and tracking sports events, built with Kotlin and a fully modular Clean Architecture (data / domain / ui). Implements the MVI pattern with Jetpack Navigation and features event browsing, search, favourites, and rich detail views.
